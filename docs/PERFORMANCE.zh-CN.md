# CPU 与整机放电遥测报告

## 当前版本与测试条件

2026-11-12。被测程序是用户测试通过的2026.2.5桌面闪帧热修，主程序SHA256见文末；本次rc1沿用同一程序，不把打包当成另一次性能测试。

- CPU：Intel Core i9-13980HX，32个逻辑处理器。
- Windows11专业工作站版，构建26300；双屏；亮度66%；Performance电源方案；电池供电。
- 动态取色：16段、120FPS、采样上限40次/秒、自动采样深度；仅切换功能开关和采样方式。
- 目标为任务栏标记“ChatGPT”的当前Codex桌面客户端，并非另行启动的标准ChatGPT客户端。三种模式使用同一个目标和点击节奏。
- Shell先最小化其他窗口，再每4秒点击该图标，交替恢复/最小化；鼠标一直留在图标上。只操作任务栏，不操作应用内部内容。
- 顺序为关闭、自适应、连续、连续、自适应、关闭。每轮先稳定8秒，再测48秒。CPU/计数器约每秒记录，电池遥测约每5秒读取。

## 主进程 CPU

计算口径：`Δ进程累计CPU秒 / Δ墙钟秒 / 32 × 100%`。100%表示全机逻辑处理器的总时间容量；未按实际频率加权，可能与任务管理器瞬时显示不同。CPU毫秒/秒另给出未除以逻辑处理器数的进程CPU时间成本，便于避免把很小的占用率误解为零。

| 状态（两轮均值） | 主进程平均 CPU | 主进程 CPU 毫秒/秒 | Explorer CPU | 双屏成功采样/秒 | 渐变写入/秒 |
|---|---:|---:|---:|---:|---:|
| 关闭动态取色 | 0.0020% | 0.650 | 0.0696% | 0.00 | 0.00 |
| 自适应 | 0.0137% | 4.392 | 0.0839% | 0.92 | 13.32 |
| 连续 | 0.0381% | 12.201 | 0.0752% | 0.83 | 13.70 |

本次切换场景中，自适应相较连续的主进程CPU时间减少约 **64.0%**。这不是整机CPU降幅、所有场景保证或省电比例。关闭功能的两轮均值作为基线列出，没有把它隐藏或当作绝对零。

Explorer包含ExplorerTAP以及大量其他桌面工作，不能把Explorer全部CPU归因到这个功能。DWM进程CPU时间读取不可用，保留空值，不记成0；GPU开销没有独立测量。因此这里不把主进程CPU称为软件全部系统成本。

包括稳定期在内，共 **84次**点击成功翻转最小化状态，间隔 **3.983–4.014秒**。六轮测量期各12次，共72次；其余12次属于稳定期，未混入CPU计时窗口。所有测量点鼠标均在任务栏上；两种开启模式有实际采样和渐变写入，停止计数增量均为0。

这说明点击放行路径在该负载下确实工作，不代表逐帧检查了每次呈现。两种模式都受悬停保护与放行约束，实际采样均未达到40次/秒上限；该结果不能完全解释为“采样次数更少”。GDI对象各轮保持50→50，采样位图分配增量均为0。

## 整机放电：仅作补充

关闭、自适应、连续的整机平均放电遥测分别为 **46.48W、46.63W、44.96W**。读数包含整机及后台负载，排序没有形成可归因于软件的省电结论；不据此宣传省电瓦数或续航收益。

## 局限与复查

每模式只有两轮、每轮48秒，CPU计时有量化，1秒区间峰值不等于更短时间尺度峰值。后台应用没有完全隔离，窗口切换和自动化/采集本身也有开销。采集器与点击驱动的CPU均值保留在汇总JSON中；首轮采集器平均CPU高于后续轮次，属于额外干扰，尤其限制整机结果的解释。

静止画面的旧2.4实验曾测得约96.7%的主进程CPU时间降幅；那是另一个版本和负载，不作为本次每4秒切换的结果。请勿把96.7%或64%写成整机省电比例。

公开数据经过去标识导出，保留相对时间、CPU/计数器差值和点击状态，去掉本机路径、绝对时间戳、句柄、个人配置及诊断日志。数据在 [benchmarks/data](../benchmarks/data)，脚本与再现限制见 [benchmarks/README.md](../benchmarks/README.md)。参数化公开脚本只做语法/编译检查，没有冒充新的实测；当前结果来自实际运行的原脚本。

测试后原配置逐字节恢复，点击驱动正常退出。应用源码和程序未因测量而改变。
